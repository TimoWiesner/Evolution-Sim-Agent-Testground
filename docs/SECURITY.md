# Operator security note

Autonomous CLI coding agents may execute arbitrary shell commands, install packages, access the internet, and read credentials from environment/home. Workspaces and subprocess working directories are **not isolation boundaries**. Run on a disposable dedicated Linux VM/container/OS user with least privilege and no valuable secrets or production credentials. Use per-provider auth with narrow limits, monitor cost, use external VM snapshot and egress restrictions if appropriate. Only run `--allow-unsafe` after explicit local operator decision to allow autonomous full filesystem/network access; other modes may block dependency installation. In particular, `--allow-unsafe` grants Codex broad permissions and asks Claude to skip permission prompts. The script never claims OS-level sandboxing.
